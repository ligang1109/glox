# Project Rules

1. Confirm with the user before modifying any files. Discussion code examples stay in the conversation unless the user asks to apply them.
2. All comments (including doc comments) must be written in English.
3. The parser is rewritten stage by stage. `doc/grammar.md` holds one logged
   section per stage (append a new section per stage, never edit old ones;
   the last section is the current state). Read it before changing the
   parser; keep parser grammar out of `README.md`.
